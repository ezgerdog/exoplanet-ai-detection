🪐 Exoplanet AI Detection

Exoplanet AI Detection is a deep learning–based system developed during the NASA International Space Apps Hackathon 2025.
It analyzes NASA’s TESS satellite data to classify celestial objects into:

✅ Confirmed Planets (CP) – verified exoplanets

🪐 Planetary Candidates (PC) – potential but unconfirmed planets

❌ False Positives (FP) – non-planetary bodies like asteroids

Using a Deep Neural Network (DNN) optimized via Grid Search, the model achieved ~78% accuracy in detecting potential exoplanets.
A Flask-based web interface allows users to manually input or upload CSV data for real-time AI predictions.

Technologies Used:
Python, TensorFlow/Keras, Flask, NumPy, Pandas, Matplotlib, HTML, CSS
